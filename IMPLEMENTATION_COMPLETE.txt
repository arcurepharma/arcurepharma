📊 API ENDPOINTS (Ready to Use)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    POST /api/whatsapp/connect
    → Initialize WhatsApp connection
    → Returns: {success, connected, message}

    POST /api/whatsapp/send
    → Send message via WhatsApp
    → Body: {phoneNumber, message, sessionId}
    → Returns: {success, message}

    POST /api/whatsapp/chat
    → Chat with bot
    → Body: {sessionId, userMessage}
    → Returns: {success, response, timestamp}

    GET /api/whatsapp/chat?sessionId=...
    → Get conversation history
    → Returns: {messages[], found, sessionInfo}

    GET /api/whatsapp/conversations
    → List all conversations
    → Query: ?status=Active&limit=50
    → Returns: {success, conversations[], count}

    POST /api/whatsapp/conversations
    → Update conversation status
    → Body: {sessionId, action}
    → Returns: {success, message}
